## 学习路线

- [ ] 基础：Python、线性代数、概率统计与深度学习
- [ ] 模型：注意力机制、Transformer、分词与位置编码
- [ ] 训练：预训练、监督微调与偏好对齐
- [ ] 应用：提示词、RAG、工具调用与 Agent
- [ ] 工程：推理、量化、部署与评测

- 文件名采用 `YYYY-MM-DD-topic.md`。

- 引用资料时保留原始链接；代码实验记录环境、参数与结果。
